## Resumen
Este módulo gestiona altas de usuario mediante el endpoint `POST` descrito aquí:  
**API Users**  
Repositorio del backend https://github.com/gnc/backend-usuarios

2. Verificar respuesta **200 OK** y campos obligatorios.
